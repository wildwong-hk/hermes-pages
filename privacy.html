This policy describes the private, single-user automation tool on the Hermes home page. It covers what the tool accesses, how that data is stored, and how access can be revoked.

1. What this application is

“Hermes” is a private, single-user automation tool operated by, and solely for, Ken Wong (wildwong@gmail.com). It is not distributed to the public and has no other users.

2. What data it accesses

When the operator authorises it, Hermes accesses the following data belonging to the operator’s own Google Account only:

  • Gmail — read messages, compose and send messages, modify labels
  • Google Calendar
  • Google Drive
  • Google Docs and Google Sheets
  • Google Contacts (read only)

Access is used exclusively to carry out tasks the operator explicitly requests, such as searching mail, drafting replies, or filing documents.

3. How data is stored

OAuth access and refresh tokens are stored locally on the operator’s own private server and are never shared.

Message and document contents are processed transiently in memory in order to fulfil a request. No copies of Google user data are retained afterwards.

4. Data sharing

No Google user data is sold, rented, shared or transferred to any third party. Hermes uses no advertising, profiling or analytics services.

5. Data retention and deletion

No Google user data is retained beyond the transient processing described above. The operator can revoke access at any time at myaccount.google.com/permissions, which immediately invalidates the stored tokens.

6. Limited Use disclosure

Hermes’ use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
